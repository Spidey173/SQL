# SQL Practice & Notes 🚀

## 📁 Repository Structure

- `01_Basics/` - Fundamental SQL queries (SELECT, WHERE, ORDER BY, etc.)
- `02_Aggregations/` - GROUP BY, HAVING, Aggregate functions (COUNT, SUM, AVG, MAX, MIN)
- `03_Joins/` - INNER, LEFT, RIGHT, FULL, CROSS JOINs
- `04_Subqueries_CTEs/` - Nested subqueries, Common Table Expressions (WITH clauses)
- `05_Window_Functions/` - ROW_NUMBER, RANK, DENSE_RANK, LEAD/LAG, Running totals
- `06_Practice_Problems/` - Step-by-step problem sets and solutions
